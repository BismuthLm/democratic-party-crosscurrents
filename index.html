METHODOLOGY / VERSION 2.1

What this index does—and does not do

Formal caucus index

Compares the Congressional Progressive Caucus, New Democrat Coalition and Blue Dog Coalition using public, sourced measures. Membership overlaps are preserved; broad-wing momentum is excluded by default.

Broad-wing results

Separately codes high-salience primaries using self-identification, official memberships, endorsements, issue positions or clearly labelled editorial inference.

Normalisation

For each complete active measure, the highest observed faction receives 100 and the lowest receives 0. Ties receive 50. Domain scores average their active measures, then use your visible weights.

Guardrails

A nomination win is not a general-election win. Unitemized FEC receipts are not donor counts. PAC money is not all allied spending. Zeros can mean “none tracked,” so incomplete measures stay out of the default score.

The headline score is sensitive to editorial choices. Use the domain scores, race table and underlying measures before drawing a conclusion.
