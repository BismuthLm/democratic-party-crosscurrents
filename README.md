# Democratic Party Crosscurrents

A small, static, source-first dashboard for mapping points of contention and areas of overlap within the Democratic coalition. It treats labels as lenses, not fixed camps, and separates reported signals from interpretation.

## Run locally

Open `index.html` directly, or serve the folder with any static server.

## Updating the tracker

Edit `src/data.js`. Each entry needs a source URL, a publication date, a confidence level, and a short neutral summary. Do not add an item based only on a social-media post or anonymous assertion.

## Principles

- No literal-war framing: this is a tracker of political disagreement and coalition strategy.
- Every current claim must be linked to its primary or high-quality reporting source.
- Uncertainty, unresolved questions, and missing evidence stay visible.
- The starter dataset is illustrative and must be reviewed before publishing as reporting.
